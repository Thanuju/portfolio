My Projects

Driver Drowsiness Detection System

Developed a real-time AI-based drowsiness detection system that monitors a user's eye movements using computer vision techniques. The system detects faces and eyes using OpenCV Haar Cascade models and determines drowsiness by tracking eye closure over consecutive frames. When drowsiness is detected, it triggers an alert to notify the user. The application is built using Python (Flask) for the backend and HTML, CSS, and JavaScript for the frontend interface, providing live video streaming and real-time feedback. This project demonstrates practical implementation of computer vision, real-time processing, and full-stack web development.
